# redmine-cli v0.2.2

This maintenance release fixes the source-release publication workflow. It
waits for a newly created draft release and all four uploaded assets to become
visible through the GitHub API before verifying their names, sizes, and SHA-256
digests and publishing the release. Unexpected or mismatched assets still stop
publication, and the final job remains checkout-free.

There are no CLI, credential, JSON contract, or skill changes from v0.2.1.
