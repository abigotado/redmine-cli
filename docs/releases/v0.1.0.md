# redmine-cli v0.1.0

The first release provides a provider-neutral, read-only Redmine CLI and one
canonical Agent Skill for Codex and Claude Code.

Highlights:

- arbitrary named profiles with no implicit company, account, or default;
- API tokens stored in native macOS Keychain through Security.framework;
- read-only current-user, project, and issue commands;
- a stable v1 JSON machine contract with typed recovery-oriented exit codes;
- bounded fields, pages, response bodies, and query-bound opaque cursors;
- guarded skill installation for Codex, Claude Code, or both;
- source-building Homebrew distribution for the supported macOS credential
  backend.

This release is source-only. Linux and Windows credential storage is not yet
supported, and downloadable macOS binaries are intentionally omitted until a
Developer ID signing and notarization path exists.

Review `SECURITY.md` before choosing the local macOS account that will store
Redmine credentials.
