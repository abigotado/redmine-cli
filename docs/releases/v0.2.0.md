# redmine-cli v0.2.0

This minor release adds bounded, explicitly confirmed Redmine mutations while
preserving the versioned JSON envelope and native credential boundary.

Added:

- issue and project creation and edits, each requiring `--profile` and `--yes`;
- project-file listing and single-file upload; and
- attachment download through a direct, validated attachment-ID route with
  bounded raw output.

`--dry-run` renders a sanitized preview without accessing Keychain, Redmine, or
file contents. Writes are never automatically retried: an uncertain result uses
exit code 10 and must be checked in Redmine before retrying.

Project visibility uses Redmine's `is_public` attribute. Attachment filenames
are repeatable values, so commas remain part of a filename. Download requests
are built solely from the numeric attachment ID; server-supplied content URLs
are displayed only as untrusted metadata and never determine a credentialed
route.

This release also includes the unreleased local-validation, profile-lock,
Retry-After, release-publication, and Homebrew fixes previously drafted for
v0.1.1.
